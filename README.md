# 🏥 Hospital Data Analysis using SQL

## 📌 Project Overview
This project analyzes hospital data using SQL queries to extract meaningful insights related to patients, doctors, departments, hospital stays, and medical expenses.

The objective was to practice SQL concepts by solving real-world business problems using a healthcare dataset.

---

## 🎯 Objectives
The project answers the following questions:

1. Total number of patients across all hospitals
2. Average number of doctors per hospital
3. Top 3 departments with highest patient count
4. Hospital with maximum medical expenses
5. Daily average medical expenses
6. Longest hospital stay analysis
7. Total patients treated per city
8. Average length of stay per department
9. Department with lowest number of patients
10. Monthly medical expenses report
